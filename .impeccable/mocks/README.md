# Direction approval record

## Round 1 — four directions (2026-08-01)

Built as live mockups at `/styles` with the real catalogue, so the comparison
was about design rather than description. Captured to `.impeccable/shots/`.

| # | Direction | Depth device |
|---|---|---|
| A | Aesop / COS / Kinfolk | offset blocks, overlap, no shadow |
| B | Glossier / Mejuri | stacked planes, soft layered shadow |
| C | Jacquemus / Bottega | scale collision, broken grid |
| D | Muji / Scandinavian | hairline grid, one plane lifted |

**User: "I like A and B both."**

## Round 2 — two blends

H1 *Editorial warm* (putty, sharp corners, offset-block depth) and
H2 *Soft elevated* (blush, rounded, stacked-plane depth). Both kept the
Instrument Serif display and restored plum, which A and B had dropped.

**User chose H2**, with a correction: the palette was invented blush and
lilac, so the logo would have stood out if placed on it.

## Round 3 — H2 rebuilt on the logo's palette · APPROVED

Palette resampled from `klik logo.png`: plum `#3c2848` (82% of the mark),
cream `#ffe4c4` (15%), orange `#ffa444` (0.7%). Those three became the whole
page — ink, paper, accent — and the illustrations were redrawn in them.

**User: "Yes, it looks nice now. Continue with building everything else."**

This is the direction the shipped homepage implements. The `/styles` route was
deleted once it was confirmed; the captures remain in `.impeccable/shots/`.
